## Proses Pengembangan
Pembuatan lingkungan (*environment*) MangObby mengandalkan kombinasi aset dari *toolbox* publik di Roblox Studio yang dikurasi dengan cermat agar menyatu dengan estetika pulau terbang, serta penambahan berbagai struktur bangunan kustom buatan sendiri sesuai dengan visi kreatif saya.

Untuk menunjang pekerjaan, saya memanfaatkan beberapa perangkat lunak:
- **Roblox Studio:** *Game engine* utama untuk penempatan level, pembuatan blok, serta pengaturan *lighting*.
- **Antigravity IDE & Lua:** Digunakan untuk penulisan skrip logika (meskipun saya memanfaatkan sistem *checkpoint* gratis dari *developer* lain guna mempercepat proses).
- **Adobe Photoshop & Canva:** Digunakan untuk pembuatan *thumbnail* game, UI pendukung, serta aset gambar 2D lainnya.

Map ini dirancang sedemikian rupa untuk menghadirkan pengalaman rintangan yang rileks, sederhana, namun tetap seru bagi para pemain. Terima kasih telah berkunjung dan mencoba!

# Develop Roblox Map: MangObby

![](/images/roblox-mangobby/roblox-1.webp)
![](/images/roblox-mangobby/roblox-2.webp)

**MangObby** is a classic obstacle course (obby) game map in Roblox, set high above the clouds on a series of floating islands. Players must jump and navigate through carefully designed simple obstacles from one island to another to reach the finish line.

## Development Process
The creation of the MangObby environment relies on a combination of carefully curated public toolbox assets in Roblox Studio that blend with the floating island aesthetics, alongside custom-built structural additions that match my creative vision.

To support the development workflow, I utilized several software tools:
- **Roblox Studio:** The primary game engine for level placement, block building, and lighting setup.
- **Antigravity IDE & Lua:** Used for scripting logic (although I utilized a free checkpoint system from another developer to speed up the process).
- **Adobe Photoshop & Canva:** Used for creating game thumbnails, supporting UI, and other 2D image assets.

This map is designed to provide a relaxed, simple, yet engaging obstacle experience for players. Thank you for visiting and trying it out!
