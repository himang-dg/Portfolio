## Ringkasan Proyek

Portfolio Aldhea Prita Amara adalah website portfolio personal yang dirancang untuk memperkenalkan profil profesional, pengalaman kerja, keahlian, tools yang dikuasai, serta berbagai proyek kreatif yang telah dikerjakan.

Website ini dibangun dengan pendekatan modern menggunakan Next.js App Router, React, TypeScript, Tailwind CSS, dan Framer Motion. Selain menampilkan informasi personal, website ini juga menyediakan katalog proyek interaktif dengan dukungan gambar, video, filter kategori, modal detail proyek, navigasi media, dan konten Markdown.

Portfolio ini memosisikan Aldhea sebagai seorang profesional kreatif yang memiliki keahlian pada bidang:

- Graphic Design
- Content Creation
- Social Media Specialist
- Video Editing
- Copywriting
- Visual Communication
- Generative AI
- Prompt Development
- AI Content Production

## Masalah yang Diselesaikan

Website ini menyelesaikan beberapa kebutuhan utama dalam proses personal branding dan presentasi karya profesional.

### 1. Menyatukan berbagai jenis karya dalam satu platform

Karya desain grafis, konten media sosial, video, serta eksperimen AI dapat ditampilkan dalam satu website yang terstruktur dan mudah dinavigasi.

### 2. Menampilkan profil profesional secara lebih meyakinkan

Website menyediakan bagian khusus untuk:

- Perkenalan personal
- Ringkasan pengalaman
- Keahlian dan tools
- Riwayat kerja
- Detail proyek
- Informasi kontak

Hal ini membantu calon klien, recruiter, atau perusahaan memahami latar belakang profesional secara lebih cepat.

### 3. Mengurangi ketergantungan pada portfolio statis

Berbeda dengan portfolio berbasis satu halaman gambar atau PDF, website ini memungkinkan setiap proyek memiliki:

- Judul
- Kategori
- Nama perusahaan atau klien
- Daftar tools
- Deskripsi pekerjaan
- Galeri gambar
- Media video
- Tampilan detail dalam modal interaktif

### 4. Memudahkan pengelolaan konten proyek

Data proyek disimpan dalam file Markdown dengan metadata frontmatter. Dengan pendekatan ini, proyek baru dapat ditambahkan tanpa harus mengubah struktur komponen utama website.

### 5. Menjangkau audiens lokal dan internasional

Website menyediakan dukungan dua bahasa:

- Bahasa Indonesia
- Bahasa Inggris

Pengunjung dapat mengganti bahasa melalui tombol language switcher pada navigasi.

### 6. Menyediakan pengalaman pengguna yang modern

Website menggunakan animasi, efek glassmorphism, transisi, hover state, modal media viewer, serta layout responsif agar tetap nyaman digunakan pada perangkat mobile, tablet, dan desktop.

### 7. Markdown-Based Content Management

Konten proyek disimpan dalam file Markdown di lokasi:

```text
src/content/projects/
```

Setiap file menggunakan format frontmatter seperti:

```yaml
---
title: "Nama Proyek"
category: "Desain Grafis"
company: "Nama Klien"
tags: ["Figma", "Adobe Illustrator"]
coverImage: "https://example.com/cover-image.jpg"
media:
  - type: "image"
    url: "https://example.com/project-image.jpg"
---
```

Isi proyek kemudian ditulis dalam Markdown dan diproses menggunakan:

- `gray-matter` untuk membaca metadata frontmatter
- `react-markdown` untuk merender konten Markdown menjadi elemen HTML

Pendekatan ini membuat pengelolaan konten lebih modular, sederhana, dan mudah dikembangkan.

## Arsitektur Aplikasi

Alur utama aplikasi bekerja sebagai berikut:

1. `src/app/page.tsx` menjadi entry point halaman utama.
2. Halaman utama memanggil `getAllProjects()` dari `src/lib/projects.ts`.
3. Fungsi tersebut membaca seluruh file Markdown dari `src/content/projects/`.
4. Metadata proyek diproses menggunakan `gray-matter`.
5. Data proyek dikirim ke komponen `Projects`.
6. Komponen `Projects` menampilkan project card, filter kategori, dan detail modal.
7. `LanguageProvider` mengatur bahasa aktif antara Bahasa Indonesia dan Bahasa Inggris.
8. Konten UI diambil dari `src/lib/i18n.ts`.
9. Terjemahan detail proyek berbahasa Inggris dikelola melalui `src/lib/projectTranslations.ts`.
10. Semua komponen dirender dalam layout utama yang didefinisikan pada `src/app/layout.tsx`.

> Interactive personal portfolio website for Aldhea Prita Amara, featuring graphic design projects, social media campaigns, content creation work, professional experience, and Generative AI experiments. Built with Next.js, React, TypeScript, Tailwind CSS, Framer Motion, and Markdown-based project content management.

---

## Deskripsi Bahasa Indonesia

> Website portfolio pribadi interaktif milik Aldhea Prita Amara yang menampilkan karya desain grafis, social media, content creation, video editing, pengalaman profesional, serta eksplorasi Generative AI. Dibangun menggunakan Next.js, React, TypeScript, Tailwind CSS, Framer Motion, dan sistem pengelolaan konten proyek berbasis Markdown.
